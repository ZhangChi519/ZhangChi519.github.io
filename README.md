# ZhangChi519.github.io

个人学术主页 | Personal Academic Homepage

基于 [Academic Pages](https://github.com/academicpages/academicpages.github.io) 模板构建。

## 主要内容

- **关于我** - 个人简介、研究方向、教育背景、工作经历
- **发表论文** - 代表性学术论文
- **项目** - 科研项目经历
- **荣誉奖励** - 获奖情况和专利
- **学生培养** - 指导学生信息
- **最新动态** - 最新消息

## 技术栈

- Jekyll
- GitHub Pages
- Markdown

## 本地运行

```bash
bundle install
bundle exec jekyll serve
```

然后访问 http://localhost:4000
